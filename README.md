# Central do Maldad

La central de Evvil: calendario, quests, caja, achievvilments y un pasatiempo para aplastar solcitos.

- **Cómo funciona:** es una app web que se instala en el celu. En iPhone, desde Safari: Compartir → Agregar a inicio. En Android, desde Chrome: ⋮ → Instalar app.
- **Datos:** viven en una base compartida de Supabase. Este repositorio no tiene datos de la banda, solo la app.
- **Quién sos:** cada dispositivo elige una vez quién es (Jero, Mica o Fran) y lo recuerda.
- **Modo demo:** sin `js/config.js` completo, la app arranca en modo demo y guarda todo en el navegador.

Hecha a mano, sin build: `index.html`, `css/app.css` y los scripts de `js/`.
